# Security policy

Security fixes target the latest published Stemmio release. Do not disclose a
suspected vulnerability in a public Issue.

Use [private vulnerability reporting](https://github.com/Charleyli925/Stemmio-Releases/security/advisories/new)
and include the affected version, safe reproduction steps, impact and any
suggested mitigation. Do not access data that is not yours or publish details
before a fix is available.
