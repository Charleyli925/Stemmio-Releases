# Stemmio support

Use this repository's Issues for reproducible product bugs and focused feature
requests. Include the Stemmio version, macOS version, Apple-silicon hardware,
expected behavior, actual behavior, and the smallest safe reproduction.

Do not attach confidential HTML, production files, credentials, account data,
local paths, screenshots with private content, or raw diagnostic logs. For a
security issue, use the private reporting route in [SECURITY.md](SECURITY.md)
instead of an Issue.
